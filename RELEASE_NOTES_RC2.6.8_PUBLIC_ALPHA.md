# PHANTOMS-LOG RC2.6.8 — Playable Public Alpha

PHANTOMS-LOG is being published as a playable alpha rather than a stable 1.0 release.

The project already supports a functioning RPG loop and a large simulation/runtime base, but several systems remain experimental or incomplete.

## Highlights

- persistent text-RPG runtime
- free-form player input
- character creation, locations, inventory, loot, crafting, trade and quests
- persistent social and faction systems
- NPC memory and lived-experience systems
- weather, dynamic events, regional content and survival pressure
- first public NPC self-protection/security behavior gate
- GPL-3.0 open-source release

## Validation

During public-release preparation:

- NPC lived-experience module: 21/21 tests passed
- primary unit-test discovery: 1241 tests passed

## Direction

The project intentionally starts as text-first AI gaming. Future work includes procedural biome/world generation, deeper persistent NPC life, local LLM integration, training/fine-tuning, API adapters, generated backgrounds and a future graphics layer.
